# SagaAgenda - Volksvagen
O SagaAgenda é um sistema de agendamento inteligente desenvolvido como projeto final da disciplina Engenharia de Software (GBC064) da Universidade Federal de Uberlândia (UFU) em 2025.

O sistema foi idealizado para a concessionária Saga Volkswagen, com o objetivo de otimizar o processo de entrega de veículos vendidos, oferecendo mais autonomia para o cliente e melhorando a coordenação entre vendedores, preparadores e entregadores.

# Funcionalidades Principais

📅 Agendamento de entregas: cliente escolhe data e hora da entrega a partir da disponibilidade definida pelo vendedor.

🛠 Gestão de vendas: cadastro completo com dados do cliente, veículo, acessórios, embelezamento e emplacamento.

🔔 Notificações automáticas: confirmações e lembretes para clientes, vendedores e entregadores.

📊 Relatórios gerenciais: emissão de relatórios de vendas e saídas de veículos.

📥 Exportação de cronograma: funcionários podem gerar cronogramas em PDF para melhor comunicação interna.

📝 Rastreamento de alterações: histórico de modificações em dados de vendas.

Clientes (compradores de veículos)

# Problemas Resolvidos

Conflitos de horários entre clientes e entregadores.

Baixa eficiência no agendamento de entregas.

Falta de autonomia do cliente para escolher o melhor horário.

Controle manual e descentralizado das etapas de preparação e entrega.

Necessidade de relatórios e notificações automáticas.
